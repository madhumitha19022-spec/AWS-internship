Internship Capstone Project Overview

This project was conceived and implemented as a rigorous capstone demonstration of AWS Cloud Architecture, Full-Stack Python Development, and DevOps Automation. The primary objective is to build a complete, resilient, and enterprise-grade Student Internship Portal, migrating away from non-standard default cloud configurations to an isolated, least-privilege, fully-monitored infrastructure.

Every architectural component was designed with strict governance principles:

Custom VPC Networking

Total control over CIDR block (10.0.0.0/16), dedicated public subnet (10.0.1.0/24), route tables, and custom Internet Gateway.

Zero Hardcoded Secrets

No AWS Access Keys or credentials are stored in code or configuration; EC2 interacts with S3 solely via IAM instance profiles.

Automated Monitoring

Instant notification of CPU spikes (>70%) and hardware/system failure checks via CloudWatch alarms and Amazon SNS email delivery.

Cost Governance

100% Free Tier compliant design with automated AWS Budgets alerts to guarantee zero unwanted charges.
