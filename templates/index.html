Project Background

Enterprise Cloud Architecture Built for Resiliency and Security

This project delivers an enterprise-grade Student Internship Portal built from the ground up to demonstrate best practices in cloud architecture, network isolation, security policies, and DevOps automation on Amazon Web Services (AWS).

Rather than relying on default VPC configurations or unmonitored deployments, this infrastructure deploys a dedicated Custom VPC with controlled routing, isolated security groups, zero hardcoded credentials via IAM instance roles, automated EBS snapshot disaster recovery, and real-time Amazon CloudWatch alarming.

IAM Least Privilege

Role-based temporary credentials via STS instance profile without exposing static AWS secret keys.

Isolated Custom VPC

VPC CIDR 10.0.0.0/16 with dedicated public subnet 10.0.1.0/24 and custom route table.

CloudWatch & SNS

Automated CPU > 70% threshold alarms with instant SNS email alerts to administrator.

Cost Control & Budgets

100% Free Tier compliant design avoiding expensive NAT Gateways, ALBs, or RDS instances.

Core Project Objectives & Deliverables

  • Custom Network Topology: Build an isolated AWS VPC, configure public subnets, attach Internet Gateway, and enforce strict security groups.
  • Linux Web Application Deployment: Deploy Python Flask with Gunicorn service manager behind an Nginx reverse proxy on EC2.
  • Role-Based S3 Integration: Secure private object bucket communication strictly through IAM instance profiles with zero credentials hardcoded.
  • Log Analytics & Visualization: Develop a standalone Python analytics engine parsing 750+ web access logs with interactive Chart.js dashboards.
  • Automated Monitoring & Cost Control: Configure CloudWatch alarms, SNS notifications, EBS snapshot backup drills, and AWS Budget thresholds.
